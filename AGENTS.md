# JayTreeLLC — JayTree development continuity (all chats)

Before any work, read this file, `docs/handoff/JAYTREE_START_HERE.md`, `docs/handoff/JAYTREE_STAGE_LOG.md`, and any existing project-specific instructions. Inspect the latest GitHub branch/commits and working tree. Do not replace an existing working system.

**MANDATORY at every coherent stage and before switching chats:** commit and PUSH all non-sensitive source, tests, assets, documentation, and QC/rollback evidence to the correct GitHub repository and branch. Verify the remote commit SHA. Update START_HERE (current truth/next actions) and append a dated milestone to STAGE_LOG. Do not call a stage complete without these. If blocked, preserve a recoverable local/LAN snapshot, record `GITHUB_PUSH_PENDING`, and clearly identify the next step. WIP branches and draft PRs are acceptable. Never force-push or overwrite collaborators' work.

Distinguish implemented / tested / installed / production certified. Record exact tests, blockers, safe artifact locations/hashes, active work branches, and rollback. No invented results. Keep private data, credentials, secrets, databases, personal images and large generated binaries off GitHub. Do not consume paid resources or CI minutes by default. Preserve security gates and existing project instructions.

Canonical cross-project policy: https://github.com/jaytreeranch/JayTreeLLC/blob/main/docs/JAYTREE_DEVELOPMENT_CONTINUITY_POLICY.md
